# 文献版图与创新边界调研 Skill

[English](README.md)

这是一个面向 Codex 及兼容 Agent 工作流的文献调研 skill。它主要解决两个常见问题：

1. 文献检索不全面，尤其容易遗漏近期工作、异名工作和相邻领域工作，导致提出想法后才发现已有高度相似论文。
2. 创新判断过于二元化：要么因为“已经有人做过相关方向”就否定整个课题，要么因为没搜到完全相同的表述就夸大创新。

这个 skill 的目标不是承诺绝对穷尽全部文献，而是让检索范围、查漏过程、停止条件和剩余盲区都可以审计；同时把“有没有人做过”转化为“还能主张什么贡献，以及需要什么证据才能成立”。

## 核心机制

### 1. 三路检索

- **经典文献线：** 综述、奠基工作、领域分类和标准基准。
- **近期文献线：** 当前及近年论文、预印本、会议接收列表、在线优先论文和活跃研究团队。
- **对抗性近邻线：** 主动寻找最可能推翻创新主张的论文，包括使用不同术语的工作、相邻任务、组件级先例和跨领域研究。

强种子论文还会继续向以下方向扩展：

- 向后引用与向前引用；
- 相似论文和共同引用网络；
- 作者、实验室和会议追踪；
- 历史术语、别名、结果导向词和组件组合检索。

最终必须报告检索日期、时间截点、信息源、纳入范围、饱和依据和剩余盲区。

### 2. 最近邻工作比较

调研不会只列出一批“代表性论文”，还必须找出最接近、最可能削弱创新主张的已有工作，并从以下维度比较：

- 问题定义与目标能力；
- 场景、假设和约束；
- 机制、架构或算法；
- 数据、监督、反馈和工具；
- 理论对象或解释性主张；
- 评测方式、基准、数据集和产物；
- 效率、规模、鲁棒性、安全性和可靠性；
- 科学价值或实际价值。

### 3. 从二元创新转向贡献边界

结论被划分为：

- **已经建立：** 相同核心主张及相应证据已经存在，不能再作为新贡献。
- **拥挤但可改进：** 大方向已知，但仍存在重要限制、机制缺口或证据缺口。
- **可能形成差异：** 具体差异可能成为贡献，但必须证明它带来了重要后果。
- **高风险探索：** 缺少研究基础、机制解释、可行性证据或低成本证伪路径。

推荐使用条件式结论，而不是简单宣判“能做/不能做”：

> 宽泛想法 A 已有研究基础，因此不能再声称 A 本身是新的；但更窄的贡献 Y 仍可能成立，前提是实验或分析 Z 能将它与最接近工作 B、C 区分开。

### 4. 创新必须连接价值

每个候选贡献都需要完成这条证据链：

**具体差异 → 作用机制 → 预期后果 → 测量方式 → 科学或实际价值**

如果其中某一环缺失，skill 会要求补充证据，而不是用更强的措辞包装它。

## 预期输出

完整调研通常包括：

- 调研范围、检索日期、文献截点、检索来源和纳入政策；
- 领域分类图或时间发展脉络；
- 经过核实的代表论文及其实际贡献；
- 最接近已有工作的逐项比较；
- 已建立、弱差异、有条件可辩护和高风险部分；
- 最小验证方案与论文级完整验证方案；
- 未解决检索、访问限制、剩余盲区和置信度。

如果当前没有实时联网检索能力，skill 会明确把近期文献和新颖性结论降级为暂定判断，不会声称“已经全面检索”或“尚无人研究”。

## 安装

PowerShell：

```powershell
git clone https://github.com/Imironman123/literature-landscape-review-skill.git "$env:CODEX_HOME\skills\literature-landscape-review"
```

Bash：

```bash
git clone https://github.com/Imironman123/literature-landscape-review-skill.git "$CODEX_HOME/skills/literature-landscape-review"
```

如果没有设置 `CODEX_HOME`，请把仓库放入当前 Agent 所支持的 skills 目录。请保留 `SKILL.md`、`references/` 和 `agents/` 的相对位置。

## 使用示例

```text
使用 $literature-landscape-review 调研“世界模型驱动的自主 Agent”。
检索截至今天的近期文献，主动寻找最可能与我的想法冲突的已有工作，
给出最近邻论文比较，并判断哪些贡献不能再主张、哪些贡献在何种证据下仍然成立。
```

```text
使用 $literature-landscape-review 评估下面的研究想法。不要因为方向已有相关工作就直接否定；
请建立多维贡献比较，给出最窄的可辩护贡献、主要失败风险，以及最小验证实验和论文级实验方案。
```

更多示例见 [`docs/prompt-examples.md`](docs/prompt-examples.md)。

## 使用边界

- 任何“最新”“尚无人研究”的结论都依赖实时检索能力和明确的时间截点。
- 搜不到完全相同的关键词不等于没有相关先例。
- 搜索结果摘要和 AI 生成摘要不能替代对原论文的核实。
- 预印本、会议版和期刊扩展版需要识别版本关系，避免重复计数。
- “首次把 X 用于 Y”本身通常不是强贡献，除非 Y 带来新的技术挑战，并且工作确实解决或揭示了该挑战。
